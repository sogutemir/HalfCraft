## Migration decision

Keep `skse/`, upstream protocol, gameplay Fabric/mixins available as reference. First milestone uses separate small HalfCraft layout and Fabric bridge profile, retaining build/toolchain and FFM/seqlock concepts. No upstream teleport, hidden-window, combat, collision or compositor hooks activate in that profile. Position snapshots remain native-space observations. No fake heartbeat is accepted as real-game proof.

GitHub CLI was absent (`gh auth status`: command not found). Local clone has `upstream`; `origin` awaits authenticated fork creation. No invented user repository URL.
